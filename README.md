# 📍 RememberGo

> Recuerda. Llega. Comparte.

RememberGo es una app Android que combina **recordatorios inteligentes por ubicación y hora**, **rutas seguras con IA** y **grupos colaborativos** en una sola aplicación.

## ✨ Módulos

| Módulo | Descripción |
|---|---|
| 🔔 Recordatorios | Alertas por ubicación, hora o ambos |
| 🗺️ Rutas seguras | Genera rutas evitando zonas peligrosas con IA |
| 👥 Grupos | Ubicación en tiempo real y chat colaborativo |

---

## 🛠️ Stack

- **Android:** Kotlin + Jetpack Compose
- **Backend:** FastAPI + PostgreSQL (Render)
- **Mapas:** OpenStreetMap + OSRM
- **Tiempo real:** WebSocket
